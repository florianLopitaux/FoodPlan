À propos du projet

Cette application est d'abord née d'un besoin personnel pour en finir avec les fameuses questions qui hanter mon quotidien : "Qu'est-ce qu'on mange ce soir ?" ; "Quoi acheter aux courses ?"
J'ai ainsi créé un outil pour mieux organiser mes repas et éviter de toujours manger les mêmes choses. Ainsi, pendant longtemps ce projet n'était qu'un petit outil, dont je me servais, plus proche du script que de l'application.

Puis la fin de mes études approchant, j'ai eu l'idée de reprendre ce projet de zéro et de le développer en tant que réelle application propre, comme si j'étais dans un environnement professionnel, afin qu'il me serve dans mon futur de Portfolio.
Voici donc l'histoire de MealPlanner, mon application web entièrement développée avec des technologies que je maîtrise et que je souhaite utiliser dans ma vie professionnelle plus tard en tant qu'Ingénieur et Développeur Logiciel.

Stack utilisé pour l'application

  • Spring Boot
  • Spring Security
  • JPA / Hibernate
  • MySQL
  • Modern Angular (17+)
  • HTML5
  • Sass / SCSS
  • Git
